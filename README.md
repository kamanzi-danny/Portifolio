# Danny Kamanzi - Personal Portfolio

A responsive personal portfolio website built with HTML and Tailwind CSS, showcasing my background, technical education, awards, and key projects.

## Features

- **About Me Section:** Highlights my background as a developer and the skills I work with.
- **Projects Showcase:** Displays my technical work, including the **\*784# USSD Service**, a menu-based mobile service that works on any phone without internet.
- **Education & Background:** Outlines my academic milestones at [SCHOOL / COLLEGE].
- **Awards & Certifications:** Recognizes achievements such as [AWARD / CERTIFICATE].
- **Contact Section:** Provides direct communication channels, phone number, location ([CITY]), and social media handles.
- **Responsive Design:** Works on desktop, tablet, and mobile, with a mobile navigation menu.

## How to run this project

This project is deployed and running live on GitHub Pages. You can access it directly via the link below:

- **Live Demo:** [https://kamanzi-danny.github.io/Portifolio/](https://kamanzi-danny.github.io/Portifolio/)

### Prerequisites

To view or run this project locally, you only need:

- A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
- An internet connection (Tailwind CSS is loaded from a CDN)
- [Git](https://git-scm.com/) (optional, to clone the repository)

### Running locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kamanzi-danny/Portifolio.git
   ```
2. Open the project folder:
   ```bash
   cd Portifolio
   ```
3. Open `index.html` in your browser (double-click it, or use the VS Code **Live Server** extension).
