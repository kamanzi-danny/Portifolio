# Kamanzi Shikiri Danny - Personal Portfolio

A responsive personal portfolio website built with HTML and Bootstrap 5, showcasing my background, technical education, awards, and key projects.

## Features

- **About Me Section:** Highlights my background as an IT Engineer with working experience in the IT and services industries, covering database management systems, networking, and communication.
- **Projects Showcase:** Displays my technical work, including the **\*784# USSD Service**, Water Access Rwanda's USSD self-service code. Customers dial it from any phone, with no internet, to check their meter and account, buy water tokens via Mobile Money, retrieve their latest paid token, and check their balance and subscription status.
- **Education & Background:** Outlines my Advanced Diploma in Information Technology at RP IPRC Kigali.
- **Licenses & Certifications:** Lists certifications from Cisco (Introduction to Cybersecurity), OPSWAT (Introduction to Critical Infrastructure Protection), and Coursera (Google IT Support Specialization, Linux Server Management and Security, IT Security, System Administration and IT Infrastructure Services).
- **Contact Section:** Provides direct communication channels, email, phone number, location (Kigali City, Nyarugenge), and social media handles.
- **Responsive Design:** Works on desktop, tablet, and mobile, with a mobile navigation menu.

## How to run this project

This project is deployed and running live on GitHub Pages. You can access it directly via the link below:

- **Live Demo:** [https://kamanzi-danny.github.io/Portifolio/](https://kamanzi-danny.github.io/Portifolio/)

### Prerequisites

To view or run this project locally, you only need:

- A modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, etc.)
- An internet connection (Bootstrap is loaded from a CDN)
- [Git](https://git-scm.com/) (optional, to clone the repository)

### Running locally

1. Clone the repository:
   ```bash
   git clone https://github.com/kamanzi-danny/Portifolio.git
   ```
2. Open the project folder:
   ```bash
   cd Portifolio
   ```
3. Open `index.html` in your browser (double-click it, or use the VS Code **Live Server** extension).
